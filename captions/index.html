Set up the subtitle Agent.

Use ReaCut 0.9.0 or later on an Apple Silicon Mac.

  1. Install local speech recognition

    Run these commands in Terminal with an Apple Silicon Python 3.12 installation. The second command block downloads about 459 MiB of model files.

    python3.12 -m venv "$HOME/.venvs/reacut-speech"
"$HOME/.venvs/reacut-speech/bin/python" -m pip install "mlx-whisper==0.4.3"
    "$HOME/.venvs/reacut-speech/bin/python" - <<'PYTHON'
from pathlib import Path
from huggingface_hub import snapshot_download

snapshot_download(
    repo_id="mlx-community/whisper-small-mlx",
    revision="45f3915923c7a79a5a5b5a7d909d39aeb0e5630e",
    allow_patterns=["config.json", "weights.npz"],
    local_dir=str(Path.home() / "Models" / "reacut-whisper-small"),
)
PYTHON

  2. Select the local model

    In ReaCut, open Settings → Configure local captions…. Use Choose model folder… to select ~/Models/reacut-whisper-small. If Python is missing, use Choose Python… and select ~/.venvs/reacut-speech/bin/python. Wait until Python and Metal and Local model files both show Ready.

  3. Try the practice clip

    Use Codex from the ChatGPT desktop app or install the Codex CLI. In the Editing Agent, select Sign in with ChatGPT and finish signing in in the browser.

    Download the practice project, unzip it, and open Caption Practice.reacut in ReaCut. Select the video clip and ask Add English subtitles to this video. Play the timeline, then open Captions to edit the new cues.
