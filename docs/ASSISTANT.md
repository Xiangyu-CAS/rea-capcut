# 剪辑 Agent

ReaCut 桌面编辑器启动后，剪辑 Agent 占满右栏。点 Agent 顶部的属性图标可展开项目或片段属性。Agent 根据当前时间线、素材库和你的需求生成可编辑的粗剪，也能调整已有片段。 [国际版 CapCut 工作流对照](research/CAPCUT_DESKTOP_9_8.md)

## 连接自己的 Codex 账号

1. 点面板顶部的 **Codex** 打开连接菜单，选择后端或指定 CLI。ReaCut 会查找本机 Codex，包括 macOS 上由 ChatGPT 桌面应用提供的 CLI。关闭面板后可从工具栏重新打开。
2. 点 **登录 ChatGPT** 后在系统浏览器完成授权。凭据失效后可用同一个按钮重新授权。输入框下方可切换 Codex 返回的模型和推理强度。模型选项与用量取决于账号和工作区。 [Codex 模型设置](https://learn.chatgpt.com/docs/models?surface=app)
3. 需要切换账号时，从顶部的 **Codex** 菜单退出登录。App Server 使用 ReaCut 单独的 Codex 配置，由 Codex 管理登录和刷新。若希望沿用已在终端登录的共享会话，在同一菜单中选 **Codex CLI**。已配置 Claude Code 的用户也可选择原有后端。 [Codex App Server 认证](https://developers.openai.com/codex/app-server/#authentication) · [Codex 登录方式](https://developers.openai.com/codex/auth/)

## 生成和应用剪辑

1. 从媒体库或输入框旁的 **＋** 导入素材。在素材卡片上点星形按钮可选用整份素材，也可在素材预览中标记入点和出点，点 **选段用于 Agent**。选中的片段和加入 Agent 的素材会在输入框里显示缩略图，悬停或聚焦可放大查看。点击素材标签可回看选段。
2. 输入需求后按 **Enter** 发送，按 **Shift+Enter** 换行。可以用选段编排粗剪，或裁剪、分割、移动已有片段以及调整文字、变速、音量、淡化和画面参数。**参考帧** 支持为本次请求选最多三张本地缩略图。
3. 输入框下方默认选择 **剪辑**。校验通过的直接剪辑会整批写入当前时间线，可以一次撤销。等待期间如果手动改动项目或切换时间线，请重新发送指令。
4. **预览** 模式可在播放器里查看方案，再点 **应用** 写入时间线。**问答** 模式只显示回复。消息中明确说「先预览，等我确认」或「只给建议」也会收紧本次权限。结果卡片跟踪对应编辑的撤销和重做。无实际变化的批次显示 **无改动**。
5. 工具活动和 Agent 的说明按顺序出现在对话里。连续的工具活动合在同一行，点开可看具体步骤。

从 ChatGPT 中打开 ReaCut 插件时，可以在宿主对话中提出剪辑需求，直接在编辑器里查看更新后的时间线。插件读取同一编辑器里的素材、选段和剪辑结果。 [插件工作流](CODEX_PLUGIN.md#直接操作与让-codex-剪辑)

## 自动字幕

在 Codex App Server 里选中一个带声音的片段，然后发送 **Add English subtitles to this video**。可以从空白对话选择这条示例。ReaCut 在本机识别片段内的语音，Codex 翻译带时间戳的文字，编辑器按原始时间添加一组可编辑字幕。已标记的素材选段也可用来生成字幕。只说“帮我给这个视频加上字幕”会保留原语音语言。如果缺少本地语音依赖，在对话里点 **打开字幕设置**，配置完成后重新发送请求。 [本地语音识别](LOCAL_SPEECH.md)

输入框旁的盾牌按钮显示发送内容。时间线摘要包含有限的素材名、字幕、时间和编辑参数，语音识别传递带时间戳的文字。画面输入限于用户选中的静态缩略图，整段音视频留在本机。近期对话保存在本机用户数据目录，可从连接菜单清空。

剪辑动作经过本地项目规则校验，支持锁轨保护、源范围检查和原子应用。App Server 通过 stdio 使用临时会话。可取消正在运行的请求，关闭面板和切换项目也会结束该请求。当前覆盖素材编排与已有片段编辑，整段音视频理解、口播停顿检测和生成新视频另属待实现能力。
