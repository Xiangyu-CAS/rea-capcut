# 响度统一与背景音乐压低

响度统一和自动压低都作为工程编辑保存。应用后可以撤销、重做或移除处理。预览与 MP4 / MOV 导出会应用同一组参数，并保留源文件。

## 响度统一

1. 选择有声音的片段，在右侧 **音频 → 响度统一** 打开对话框。
2. 选择目标响度，默认 **−23 LUFS**，也可以选 −16 或 −14 LUFS 等目标。
3. 点 **分析**，核对测得的综合响度、真峰值和拟应用增益，再点 **应用**。

分析测量片段当前的源入出点和变速结果。固定增益在音量关键帧、静音和淡化之外单独保存。分析上限为 60 分钟源声，增益最高 +24 dB，并按源信号的 −1.5 dBTP 真峰值上限调整。峰值受限或素材本身非常安静时，结果可能低于目标。此处的 LUFS 用于统一单个片段，导出仍会叠加其它声轨。

## 自动压低背景音乐

1. 把旁白与背景音乐放在不同轨道，保持人声轨道可听。
2. 从时间线工具栏打开 **自动压低背景音乐**。明确选择人声轨道和要处理的音乐轨道。
3. 调整活动阈值、压低量、进入和恢复时长。分析后核对活动区间数并应用。

检测会略过静音片段，按当前选段、播放速度、音量和淡化计算人声轨道的活动区间。相邻片段的重叠区间合并，短停顿保持压低。默认阈值 −40 dBFS、压低 12 dB、进入 0.12 秒、恢复 0.35 秒。想微调压低量或过渡时长，可以对该音乐轨道复用已保存的检测结果。

区间按工程时间保存。移动、裁剪、替换人声素材或修改识别阈值后，请重新分析。检测基于声级，人声轨道上的其它响声也可能触发压低。每次分析最多处理 200 个片段、合计 60 分钟源声和 512 个活动区间。
