# 剪映草稿导入边界

ReaCut 使用自己的 `.reacut` 项目格式。`importCapcutDraft` 是实验性、会丢失信息的 classic 明文 JSON 转换器，当前支持以 `tracks` 和 `materials` 组织的基础视频、图片、音频、文字片段。实现不修改原草稿、不下载远程资源，也不解密不透明载荷。

本机剪映版本 11.0.12922 的专用新建测试草稿 `draft_info.json` 不是可解析 JSON。当前不支持该载荷，不能承诺读取或回写剪映 11.0 草稿，也没有验证任意历史剪映版本的完整互通。转换器的自动化测试全部使用自行构造的 JSON，研究来源与覆盖见 [REA_FINDINGS.md](research/REA_FINDINGS.md)。

转换规则是自主实现：classic 时间范围按微秒转换为 ReaCut 秒；分别映射时间线开始、时长、源入点、0.1–8 倍基础速度、音量、位移、统一缩放、旋转、透明度及翻转。只接受 macOS/Linux 绝对路径或 Windows 盘符绝对路径，素材是否真实存在由用户重新链接/客户端核查。源时长缺失时由引用片段推断并发出警告，源范围明显越界的片段跳过。

文字只保留基本文本，字体、花字、样式和排版使用 ReaCut 默认值。剪映关键帧、曲线变速、效果、模板、转场、裁切、倒放、特殊音效与画布背景未完整映射，导入警告会列出检测到的丢失项。导入后必须按自己的预期核对预览和导出结果；要继续编辑，请保存为 `.reacut`。

云项目、账号、SaaS 和依赖 API 的 AI 功能本期留白。本实现不复制或分发剪映专有代码、库、图标、字体、模板或素材，开源仓库也不包含本地原始取证数据。
