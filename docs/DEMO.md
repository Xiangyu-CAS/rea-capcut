# 原创演示工程

在项目目录执行 `npx tsx scripts/generate-demo.ts`，然后在 ReaCut 选择「打开项目」，打开 `.demo/demo.reacut`。也可直接播放 `.demo/demo.mp4`。需要本机 FFmpeg / FFprobe 和已安装的 npm 依赖。

示例为 1280×720、30 fps、9 秒的完整本地工程，包含三个原创山水片段、持续的合成和弦、中文标题、字幕、标签、位置与缩放关键帧、调色、画面及声音淡入淡出。素材路径指向生成时的本机目录；换机器后重新执行生成命令即可。

所有画面由 `@napi-rs/canvas` 绘制的渐变、山脊、倒影与波纹组成，音频由数学正弦波合成，不下载外部素材，不使用剪映代码、素材或在线服务。固定景观随机种子为 `0x524541`；工程 UUID 与时间戳会在每次生成时更新。生成器及生成素材采用 MIT 许可。

中文使用项目内的 Noto Sans SC 开源字体（SIL OFL）；原始字体许可与来源记录位于 `public/fonts/`。浏览器和导出共同使用该字体，导出显式设置变量字重 400 / 700。

脚本同时调用真实导出引擎生成 MP4，使用 FFprobe 核对尺寸、音频流和 9 秒时长，并保存三个时刻的 `preview-1.png`、`preview-2.png`、`preview-3.png`。`.demo/` 是本地生成目录，不纳入 Git。

本机一次 1280×720 / 30 fps / 高画质导出实测为 **4.46 秒**（9 秒时间线，13 个片段，含混音、三组调色、缩放与位置关键帧、标题及字幕）；把三段视频全部改为饱和度 3 后，导出为 **7.70 秒**。这是开发机器上的单次观测，不是跨平台性能保证。静态蒙版预渲染为 Alpha PNG；普通饱和度使用 8 位原生矩阵，极高饱和度使用 16 位矩阵与 LUT，避免对颜色逐像素解析表达式。
