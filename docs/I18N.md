# UI Internationalization (i18n)

This document explains how to add translations and languages to ReaCut.

## Architecture
- `src/i18n/locales/*` contains the dictionaries. `zh-CN.ts` is the source of truth for the keys.
- `src/i18n/languageStore.ts` manages the current language state and persists the choice in `localStorage`.
- `src/i18n/useTranslation.ts` provides the `t()` hook. It supports simple variable interpolation (e.g., `{count}`).

## Adding a new key
1. Add the key and its Chinese translation to `src/i18n/locales/zh-CN.ts`.
2. Add the same key with its English translation to `src/i18n/locales/en.ts`.
3. Add the same key with its Turkish translation to `src/i18n/locales/tr.ts`.
4. (Optional) Use the key in your component: `const { t } = useTranslation(); <span>{t("my.new.key")}</span>`.
*Note: TypeScript will throw an error if a key is missing in `en.ts` or `tr.ts`.*

## Adding a new language
1. Create `src/i18n/locales/[lang-code].ts` and export the dictionary (typed as `Record<TranslationKey, string>`).
2. Add the language code to `SUPPORTED_LANGUAGES` and the dictionary to the `dictionaries` object in `languageStore.ts` and `useTranslation.ts`.
3. Add the option to the `<select>` in the Settings dialog.
