# v0.4.0 完善记录

2026-10-13。基于既有受控界面截图、当前功能矩阵和实际编辑器验收，优先处理日常剪辑路径中的差异。界面代码、图标和素材由本项目独立实现；此次没有读取私人项目或再次操作第三方服务。

| 开始时的差异 | 本轮交付 |
| --- | --- |
| 资源顺序和属性分类不同，画面工具平铺 | 素材/音频/文本/贴纸/特效/转场/字幕；画面/音频/变速/动画/调整，画面下基础/裁剪/抠像/蒙版 |
| 面板层级与选中样式差异较大 | 中性深灰、青色强调、统一标题高度、白色片段选框、红棕文字轨；缩放滑块和数字同步 |
| 三栏宽度固定 | 拖动分隔线、键盘微调、跨启动记忆、双击或 Home 恢复；小窗口保护最小可用宽度 |
| 素材只能直接放入时间线 | 单击源预览，播放/逐帧、I/O 入出点、选段加入；双击仍添加整段 |
| 字幕主要依靠时间线逐条改 | 字幕列表、搜索、多选、逐句定位/修改、批量偏移/替换/样式；锁轨、过时计划保护和一次撤销 |
| 工程依赖原文件绝对路径 | 收集工程与全部原素材，去重复制、相对路径、搬移重开、继续保存；新导入文件自动收集 |
| 只能整片导出 | 整片、选中片段覆盖区间、自定义区间；保留该时段全部画面图层和声音 |

独立复查还修复了三个问题：包内素材丢失时不能保存其他编辑；新素材已有包内副本但外部源断开后不能再保存；Escape 或原生菜单可能替换正在执行的打包弹窗。缺失素材仍需重链才能播放和导出，不会伪造恢复媒体。

## 实际验证

- 22 个测试文件，270 项通过、1 项因未内置 x265 造样编码器而跳过；类型检查与生产构建通过。
- 原有八套桌面流程回归通过：剪辑导出、视觉工具、存储恢复、播放器、声音、轨道、叠化和草稿导入。
- 最终 DMG 只读挂载后复制的应用，通过七套桌面验收共 45 项检查：安装包基础 7、素材/助手 12、字幕 8、素材包/区间 6、源预览 4、三栏布局 5、300 句字幕项目 3。
- 全部安装包套件使用空 PATH 和隔离用户目录；导出使用包内 FFmpeg/FFprobe。基础套件真实导出 1280×720、9 秒中文标题和混音；源选段及区间套件分别导出正确的一秒蓝色画面与非静音音频。
- 15 分钟、300 句合成字幕项目完成搜索定位、整批偏移/保存和一次撤销。单次本机自动化耗时：启动到时间线 542ms，搜索 46ms，检查/应用/保存 230ms，撤销/保存 150ms。这些数值包含自动化交互开销，不代表所有项目或设备的性能保证。
- DMG 校验、ZIP 完整性、严格 ad-hoc 代码签名和镜像内外 ASAR 指纹一致性通过；详细指纹见 [验证记录](VALIDATION.md)。

## 仍然存在的差异

界面和常用流程更接近，但没有达到剪映全功能或逐像素一致。多时间线编辑、曲线变速、倒放、专业颜色管理、完整动画/转场库等仍未实现。字幕没有语音识别；复杂 WebVTT 样式不会完整保留。

素材包不收集系统字体，首次 SHA-256 清单不随编辑更新。区间导出保留原时间轴合成语义，长时间线后段的导出性能仍需进一步优化。300 句字幕验证不涵盖多路高分辨率视频、长时间编辑或异常断电。

剪映草稿仍是限定已验证格式的有损只读导入。Windows/Linux、Developer ID 签名、公证及 GitHub CI 尚无本轮验证；SaaS、云同步、账号和直接 API AI 继续留白。未提交、推送或发布 GitHub。

本轮新增桌面套件已加入 GitHub Actions 的 macOS 作业，配置仅在本地更新；未推送或触发远程 CI。
